claude code最佳实践

参见：https://harper.blog/2025/05/08/basic-claude-code/
每次使用时，先编写好 prompt_plan.md ，然后输入以下提示词
typescript
1. 打开**@prompt_plan.md**文件，找出所有未标记为完成的提示。 2. 对于每个未完成的提示： - 再次确认是否确实未完成（如有疑问，请寻求澄清）。 - 若确认已完成，则跳过该项。 - 否则，按描述实现该提示。 - 确保测试通过且程序可编译/运行 - 将修改提交至仓库，附清晰的提交信息。 - 更新**@prompt_plan.md**标记该提示为完成。 3. 完成每个提示后暂停操作，等待用户审核或反馈。 4. 根据用户指示，继续处理下一个未完成的提示。
